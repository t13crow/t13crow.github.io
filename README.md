# ФАНТАЗЁР

Публичное фотопортфолио Amir Arsalan Najafi. Стамбул / Москва. Русский, English, Türkçe.

27 авторских фотографий, интерактивная галерея, полноэкранный просмотр и визуальные истории.

Публикация: GitHub Pages, ветка main, папка / (root). Файл .nojekyll нужен для обслуживания каталога _next.

GitHub Pages не исполняет серверные обработчики. Отправка заявок требует внешнего серверного размещения и настроенных сервисов; до настройки доступен Instagram.
