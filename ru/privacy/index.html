Конфиденциальность

Форма используется для ответа на заявки о фотосъемке.

Какие данные обрабатываются

Имя, email, дополнительные контакты, выбранный город, тип съемки, дата и сообщение, которые вы сами указываете в форме.

Для чего нужны данные

Только для обсуждения вашей заявки и организации съемки. Сайт не подписывает вас на рассылки и не использует рекламные трекеры.

Сервисы обработки

Форма обрабатывается Cloudflare Workers и защищена Cloudflare Turnstile. Заявка и контактные данные передаются фотографу через Telegram. Сайт размещён на GitHub Pages.

Хранение и удаление

Заявки поступают в личный чат фотографа в Telegram. Вы можете запросить доступ, исправление или удаление своих данных, связавшись с фотографом по указанному ниже контакту. Не отправляйте через форму чувствительные сведения.

Локальные настройки

Сайт сохраняет выбор языка в функциональном cookie. Для защиты формы могут использоваться технические данные браузера. Дополнительная аналитика не подключена.
